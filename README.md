Product Sentiment Analyzer and Review Dashboard

📌 About the Project

The Product Sentiment Analyzer and Review Dashboard is a web-based application designed to analyze customer reviews of products and classify them as Positive, Negative, or Neutral. It provides an interactive dashboard with charts and visualizations to help users understand customer opinions and product satisfaction.

🎯 Objectives

- Analyze customer reviews automatically.
- Identify positive, negative, and neutral sentiments.
- Display product review insights using charts.
- Understand customer satisfaction and feedback.
- Support better product-related decisions.

✨ Features

- Product review analysis
- Sentiment classification
- Interactive review dashboard
- Sentiment charts and graphs
- Customer feedback insights
- Product-wise review visualization

🛠️ Technologies Used

- Frontend: React.js, Vite, HTML, CSS, JavaScript
- Backend: Python, Flask
- Web Scraping: Selenium, BeautifulSoup
- Sentiment Analysis: VADER / TextBlob
- Database: MongoDB
- Data Visualization: Chart.js / Recharts

⚙️ How It Works

1. Collect product reviews.
2. Process the review text.
3. Analyze the sentiment of each review.
4. Classify reviews as Positive, Negative, or Neutral.
5. Store review information in the database.
6. Display the results on the dashboard.

💻 Installation

Clone the Repository

git clone https://github.com/Jeniferyesuraja/Product-Sentiment-Analyzer-and-Review-Dashboard.git

Backend Setup

pip install -r requirements.txt
python app.py

Frontend Setup

npm install
npm run dev
